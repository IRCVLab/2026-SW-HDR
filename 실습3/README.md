# 실습 3 — 소실점 기반 Around-View (적은 대응점으로)

## 1. 문제 (실습 2에서 남은 한계)

- 일반 호모그래피 = **8-DoF** → 대응점 **4개 이상**
- 추가 조건: **non-collinear** + **전 영역 분산**
- 현실: 차량 주변 360°에 정밀 측량된 기준점을 넓게 깔기 어려움
- 근거리 한 곳에 몰린 4점 → 외삽 구간에서 오차 폭증

## 2. 열쇠 — 호모그래피의 열 분해

```
H_{g→i} = K [ r1  r2  t ]
```

- 세계 +X 무한원점 (1,0,0,0) 의 상 = **K r1 = v_X** (소실점)
- 세계 +Y 무한원점 (0,1,0,0) 의 상 = **K r2 = v_Y** (소실점)
- 결론: **소실점 2개 = H의 앞 두 열**

| 방식 | DoF | 필요 대응점 |
|---|---|---|
| DLT | 8 | 4 |
| VP 2개 | 3 (t) | **2** |
| VP 2개 + 장착높이 | 2 (C_x, C_y) | **1** |

## 3. 왜 이득인가

- 소실점 입력 = "이 선들은 세계에서 서로 평행" **뿐**
- 선의 실제 좌표·간격·원점 → **불필요**
- 재료: 주차선 / 차선 / 연석 / 타일 줄눈 / 건물 모서리 — 어디에나 있음
- 대응점 1~2개만 **축척·원점 고정** 용도로 사용

## 4. 파이프라인

1. 왜곡 보정 → 선분 검출 (LSD / HoughP)
2. RANSAC + greedy → 지배적 소실점 3개
3. K⁻¹v 내적 ≈ 0 인 쌍 선택 = **직교 방향쌍**
4. r1 = K⁻¹v₁/‖·‖, r2 = K⁻¹v₂/‖·‖, r3 = r1×r2 → SVD로 SO(3) 투영
5. m = K⁻¹x 에 대해 `[m]× t = −[m]× (r1X + r2Y)` → 최소제곱으로 t
6. 4중 모호성 해소: 지면법선 (r3[1]<0) → cheirality → 장착 방위 prior
7. 카메라별 H → BEV 워핑 → 거리변환 페더 블렌딩

## 5. 검증 결과 (합성 4카메라 리그, 지면 역투영 RMSE)

| 시나리오 | front | left | rear | right | **평균** |
|---|---|---|---|---|---|
| A. DLT 4점 · 전영역 분산 | 0.048 | 0.051 | 0.117 | 0.095 | **0.078 m** |
| B. DLT 4점 · 근거리 집중 | 0.435 | 0.877 | 0.604 | 0.101 | **0.504 m** |
| C. **VP + 2점** (B와 같은 패치) | 0.036 | 0.048 | 0.096 | 0.029 | **0.052 m** |
| D. **VP + 1점 + 높이** | 0.093 | 0.090 | 0.051 | 0.053 | **0.071 m** |

- 검출된 소실점쌍 직교각: 89.9°~90.0°
- **핵심**: B → C 는 대응점을 **4개에서 2개로 줄였는데 오차가 1/10**
- 이유: 소실점이 무한원거리 정보를 담아, 근거리 점만으로도 원거리 외삽이 안정

## 7. 실데이터 적용 시

- 입력 좌표는 **왜곡 보정 후** 픽셀 (어안은 `cv2.fisheye.undistortPoints`)
- `yaw_prior_deg`: 전/후/좌/우 장착 방위 (리그 설계값, ±50° 허용)
- 1점 모드는 `yaw_prior_deg` **필수** (식 수 = 미지수라 잔차로 구분 불가)
- 소실점 검출 실패 시 → `tol_deg` 완화(1.5→3.0), `min_len` 하향

## 8. 남은 한계 (다음 단계 = 통합 최적화)

- 지면 비평면성 (경사·요철) → 소실점 자체가 흔들림

- 소실점은 방향만 고정, **축척·원점은 여전히 대응점 의존**
